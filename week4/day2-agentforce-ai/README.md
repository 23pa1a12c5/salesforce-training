# Day 2 – Agentforce and AI

## Agentforce Summary

Agentforce is Salesforce’s AI-powered platform that helps organizations build intelligent AI agents for automating business operations and improving customer experiences.

Agentforce combines:
- Salesforce CRM data
- Automation
- AI reasoning
- Enterprise workflows

It helps businesses create AI-driven systems that can understand requests, make decisions, and perform actions automatically.

# AI Workflow Explanation

AI workflows operate using data, automation, and decision-making logic.

## Example Workflow

1. User submits a request
2. AI agent analyzes the request
3. CRM data is retrieved
4. AI decides the next action
5. Workflow automation executes tasks
6. Response is sent back to the user

# Risks of Enterprise AI

Enterprise AI systems may face risks such as:
- Incorrect AI decisions
- Data privacy concerns
- Security risks
- Biased responses
- Over-automation
- Dependency on AI systems

Organizations must carefully monitor AI systems and apply governance practices.

---

# Importance of AI Governance

AI governance helps:
- Ensure ethical AI usage
- Protect sensitive data
- Improve decision accuracy
- Maintain compliance
- Reduce operational risks

Good governance is important in enterprise AI systems.
