# Day 3 – LWC Basics

## 1. What is LWC?

LWC (Lightning Web Components) is a modern UI framework in Salesforce used to build fast and reusable web components using HTML, CSS, and JavaScript.

It helps developers create interactive and responsive Salesforce applications.

---

# 2. Why Salesforce Uses LWC

Salesforce uses LWC because it:
- Provides faster performance
- Uses modern web standards
- Creates reusable components
- Improves user experience
- Supports scalable application development

LWC is lightweight and efficient compared to older frameworks.

# 5. Frontend vs Backend Logic

| Frontend Logic | Backend Logic |
|----------------|---------------|
| Built using LWC components | Built using Apex |
| Handles UI interaction | Handles business logic |
| Uses HTML, CSS, JavaScript | Uses Apex classes and triggers |
| Displays data to users | Processes and stores data |
